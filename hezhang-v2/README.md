# 合账 v2.0 — 本地体验版

这是一个可直接打开的单文件前端原型，**不是可上线的团队财务系统**。

## 体验

打开 `index.html` 即可使用。支持手机浏览器布局、单屏记账、拍照/相册凭证、统一报销或 AA 分摊、按原账关联全额或部分冲红、时间范围筛选、简单净额报表和 CSV 导出。

## 数据说明

所有账目与图片保存在**当前浏览器的 localStorage**，不同设备之间不共享。清除浏览器数据会丢失记录；浏览器容量有限，图片可能造成存储失败。不要输入真实敏感财务数据。

## 尚未实现

- PostgreSQL 数据库、后端 API、文件对象存储
- 实时通知、评论、异议和操作审计
- 实际报销、AA 转账及结算记录
- Docker、HTTPS、服务器部署与自动备份

冲红在体验版直接生效；正式版需管理员审批，并在数据库事务中锁定原账、检查累计冲红金额、建立不可变审计流水。跨期冲红和已结算调整需另行制定会计口径。AA 分摊的分位余数按成员顺序分配。
